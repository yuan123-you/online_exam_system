# AI 题目业务：兼容性与部署前提

日期：2026-10-08。本文件不是已部署声明。本轮没有连接真实 MySQL、修改线上数据或调用真实模型。

## 阶段与编码契约

1. 模型原始文本：不可信候选。同步生成/练习只接受有效、非空 JSON 题目数组（允许标准代码围栏），每条题目须通过结构与评分契约校验。不再从异常文本制造占位题。
2. 校验后的生成预览：维持已有选择题字母答案协议，选择题的逻辑内容和顺序保持不变，格式统一为大写 A./B./C./D. 前缀，确保既有前端的练习单选键唯一；返回 JSON 的字段结构、角色权限和额度处理保持兼容。未修改前端。
3. 正式 AI 入库：重新校验，不信任客户端来自同步生成还是流式预览的声明。记录 ID 和归属由服务器决定；选择题答案规范为实际选项内容，非选择题保留参考文本。错误条目报告 index/title/message，合法条目继续导入。
4. 考试/练习评分：明确的 A/B/C/D 标签只按题目原始选项映射，不按随机显示位置映射，不从 Banana 等单词猜测字母；旧练习中实际前端选择键发生碰撞的选项集合不能被当作正确作答来计分。保留历史精确文本匹配，不改写发布快照或已有 finalScore。
5. 生成缓存：一般缓存策略保持不变；结构化生成/练习校验失败时删除对应提示词的原始响应缓存，避免 30 分钟内重复返回同一不合格候选。

## 本轮验证的题目规则

- 六个既有类型：single/multiple/judge/fill/short/coding。
- 选择题 2–4 个选项；判断题 2 个。选项及去除标签后的内容不能为空、显式字母前缀必须与位置一致，去除显式标签后内容不能重复；验证原始答案后，再规范选项格式与正式答案值。
- 单选/判断只有一个答案；多选答案须唯一且对应已知选项，不额外引入“至少两个正确选项”的新政策。
- 当前填空评分支持一个参考答案；短答和代码沿用多行参考文本语义。
- 分值为正整数，只有未提供时沿用 5 分默认值，不能把零、负数或小数静默改成 5 分。
- easy/medium/hard 以及现有提示词中文难度表述统一到数据库值。
- JSON/结构正确不代表知识正确：本轮不声称已验证模型事实、题目唯一正确性或学科内容质量。

## 解析持久化：必须先迁移再部署

现有表未保存 AI explanation。本轮新增可空 `question.explanation TEXT`，读写路径和新发布快照保留解析。学生正式考试响应同时隐藏 answer 和 explanation；教师可查看所属考试解析。旧快照不从新题库补解析。

- 新数据库：初始化 schema.sql 已包含字段。
- 已有数据库：先备份并执行一次性迁移 `D:\Codex Web\online_system\db\migrations\2026-10-08-ai-question-explanation.sql`。**CREATE TABLE IF NOT EXISTS 不会给已有 question 表补列**，因此不能仅重启应用就认为迁移完成。
- 先在隔离 MySQL 8 验证 DDL、JSON、完整导入/发布/取题链路。当前事务测试使用 H2 的可移植 VARCHAR 元数据夹具，不代替目标 MySQL 的 TEXT/JSON 驱动验证。

只读检查列是否已存在：

```sql
SELECT COLUMN_NAME
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_SCHEMA = DATABASE()
  AND TABLE_NAME = 'question'
  AND COLUMN_NAME = 'explanation';
```

列已经存在时不要重复执行 ADD COLUMN。迁移不更新历史题目、成绩或快照。不自动根据当前模型生成历史解析。

## 回滚

保留新增列和已保存解析，不做 DROP COLUMN 或数据删除。旧应用可能不读取/保存新列，应用回滚不等于数据/业务契约无损回滚；应先确认不会覆盖新元数据或重新启用占位题导入。已发布快照保持原样。

## 明确未覆盖

- 流式预览整条任务生命周期、流式输出前统一服务端校验与取消/重试；目前正式 AI 入库处再次校验。
- 非 AI 手工题库编辑入口的全面统一校验与历史坏题治理。
- 额度的并发数据库约束、重复请求的业务幂等策略，以及“再出题”是否应绕过有效结果缓存的规则。
- 练习会话完整生命周期、客户端学习记录可信度，以及主观题评分的教育业务政策。
- 模型事实正确性、真实供应商兼容性、生产数据库与多角色端到端验收。
- 既有全量测试失败；本轮不会通过禁用测试来宣称整个项目已验证。

## 复查发现的编码碰撞

类似 `["A. one", "A"]` 的原始选项会使既有练习前端的两项都产生键 A。只规范答案不足以解决错误得分与生成后无法原样入库的问题。本轮在验证原始参考答案绑定后，按原始顺序统一选项前缀，例如变为 `["A. one", "B. A"]`，不改变逻辑内容或答案位置。新预览与正式记录均能重新校验/入库；旧有键碰撞的练习不自动获得分数。原始参考答案本身有歧义时仍拒绝，不猜测意图。
